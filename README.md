Language Of Interaction (LOI). Research platform for the purpose of understanding the emergence of computation in complex systems.

# Structures to analyze

- emergence of computation from nand gates
- spiking. networks including atomata and neurons (deterministic and probabilistic)
- cellular atomata
- probabilistic atomata
- reversible and quantum circuits

# Planned analytical tools

- Graph structure analysis
- Information theoretic quantities
      - entropy, mutual information, transformation entropy, complexity
- State space analysis
      - Detect memory and state
- Graph rewriting

## AI Development

This project, its vision, and architecture were developed by me. AI tools were used as an advisory resource in debugging, discussing implementation details, and drafting simple methods and function. ~10% of the code was written by ChatGPT under strict supervision, the rest was written by me.
