Instructions:
    IADD dest src1 src2
    ISUB dest src1 src2 // src1-src2
    IMUL dest src1 src2
    IDIV dest src1 src2 // src1/src2
    IPOW dest src1 src2 // src1^src2

    FADD dest src1 src2
    FSUB dest src1 src2
    FMUL dest src1 src2
    FDIV dest src1 src2
    FPOW dest src1 src2

    AND dest src1, src2
    OR dest src1, src2
    NOT dest src   

    MOD dest src1 idx // src1 % idx  
    ITOF dest src    // Convert int to float, src must be reg

    JMP offset             // unconditional jump 

    IJEQ offset src1 src2 // Jump if equal
    IJLT offset src1 src2 // jump if less than
    IJGT offset src1 src2 // jump if greater than
    IJLE offset src1 src2 // jump if less than or equal
    IJGE offset src1 src2 // jump if greater than or equal

    FJEQ offset src1 src2 // Jump if equal
    FJLT offset src1 src2 // jump if less than
    FJGT offset src1 src2 // jump if greater than
    FJLE offset src1 src2 // jump if less than or equal
    FJGE offset src1 src2 // jump if greater than or equal

    IEQ dest src1 src2 // src1 == src2
    ILT dest src1 src2 // src1 < src2
    IGT dest src1 src2 // src1 > src2
    ILE dest src1 src2 // src1 <= src2
    IGE dest src1 src2 // src1 >= src2

    FEQ dest src1 src2 
    FLT dest src1 src2
    FGT dest src1 src2
    FLE dest src1 src2 
    FGE dest src1 src2 


    MOV dest, src 
    RET src

    RND dest // generates a random number in range [0,1)

	sources can be literal or a virtual register

    There are 64 registers, all 64 bits, registers addressed with 8 bits but top 2 ignored

    simulation timestamp put into r0
    relation delay put into r1
    n arguments are put into r2..rn+1

    little endian

    for assembler "#" makes a comment but they must be on their own line 

bits:
    a a f d d d s s

    a a:
        0 0: arithmetic instruction
        0 1: logical / arithmetic instructions
        1 0: jump instruction
        1 1: compare instrcution

    0 x f:
        0: integer arithmetic / logical operations / other math operations
        1: float arithmetic / complex arithmetic

    1 x f: 
        0: integer jumps /comparisons / other operations
        1: float jump / comparisons / other operations

    0 0 x d d d:
        0 0 0: ADD
        0 0 1: SUB
        0 1 0: MUL
        0 1 1: DIV
        1 0 0: POW
        1 0 1: ABS // not implemented yet
        1 1 0:
        1 1 1:

    0 1 0 0 d d:
        0 0: AND
        0 1: OR
        1 0: NOT
        1 1: 

    0 1 0 1 d d:
        0 0: MOD // to convert int to mod
        0 1: F2C // not implemented yet
        1 0: I2F // to convert int to float (real)
        1 1: I2C // not implemented yet


    0 1 1 d d d:
        0 0 0: CADD // not implemented yet
        0 0 1: CSUB // not implemented yet
        0 1 0: CMUL // not implemented yet
        0 1 1: CDIV // not implemented yet
        1 0 0: CPOW // not implemented yet
        1 0 1: CABS // not implemented yet
        1 1 0:
        1 1 1:

    1 0 x d d d:
        0 0 0: JMP
        0 0 1: 
        0 1 0: JEQ
        0 1 1: JNE // not implemented yet
        1 0 0: JLT
        1 0 1: JLE
        1 1 0: JGT
        1 1 1: JGE

    1 0 0 d d d:
        0 0 0: JMP

    1 0 1 d d d:
        0 0 0: RET

    1 1 x d d d:
        0 0 0: 
        0 0 1: 
        0 1 0: EQ
        0 1 1: NE // not implemented yet
        1 0 0: LT
        1 0 1: LE
        1 1 0: GT
        1 1 1: GE

    1 1 0 d d d:
        0 0 0: MOV

    1 1 1 d d d:   
        0 0 0: RND



    s s: source sources
        0 0: reg       reg
        0 1: immediate reg
        1 0: reg       immediate
        1 1: immediate immediate
